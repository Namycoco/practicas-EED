##  Contenidos del repositorio

A lo largo del curso trabajaremos los siguientes conceptos y herramientas:

| Área | Descripción |
|---|---|
| **Markdown** | Creación y estructuración de documentos, archivos README y documentación técnica. |
| **Git** | Control de versiones, registro de cambios y gestión del historial de los proyectos. |
| **GitHub** | Alojamiento de repositorios, colaboración y gestión de proyectos de software. |
| **Entornos de desarrollo (IDE)** | Conocimiento y utilización de herramientas de programación como Eclipse y Visual Studio Code. |
| **Java** | Desarrollo de ejercicios y prácticas para adquirir fundamentos de programación. |
| **Depuración** | Identificación, análisis y corrección de errores en el código. |
| **Documentación** | Elaboración de documentación técnica clara y organizada. |
